Resolution actions — workflow panel

Wireframe for GRM-119 (frames 1, 2, 3), GRM-121 (the suggestion in 2b) and GRM-122 (frame 4). Binds IA and layout only (05_frontend rule 9a.2) — not colour, not copy, not component structure. One place: a panel in the workflow editor. An admin chooses up to 8 actions for a workflow; a new local action says what it counts as nationally; the admin never chooses an action’s owner.

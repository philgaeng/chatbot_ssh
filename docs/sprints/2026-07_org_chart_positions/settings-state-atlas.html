Historical sprint artifact (2026-08-02)
Kept for the record of how the settings redesign was reasoned through. It predates two model changes and is wrong in ways that matter if used as a build reference:
  • the fixed intake “stream” / slot_key model — dropped by migration c5e7f9a1; a project now links N named workflows;
  • the standard / SEAH track model — SEAH is now an ordinary workflow with a sensitive property, and access to its grievances is cast membership only (DECISION-sensitive-workflows.md, 2026-08-02).
Current wireframes: docs/ticketing_system/ui/04_projects_packages_redesign.html (project editor) · docs/ticketing_system/ui/06_workflows_step_cast_editor.html (workflow authoring). Specs: docs/ticketing_system/12 & 13.
